# Data-subject requests (access, erasure, rectification, objection, portability)

**Deadline**: one calendar month from the day the request is received, by any
channel, in any words. Extendable by two further months only for complex or
numerous requests — tell the person within the first month.

1. **Log it the same day.** Contact page → Data protection → "Log a request",
   or Admin → Data protection if the person is not a contact. The due date is
   calculated automatically and overdue requests turn red.
2. **Confirm identity** proportionately: reply from the email we hold, or ask
   for ID only if there is real doubt. Do not ask for more than needed.
3. **Access / portability**: Contact page → "View everything held" → Print /
   save as PDF (and "Download as JSON" for portability). Check the printout for
   other people's personal data (e.g. a third party named in a note) and redact
   it. Add anything held outside the system (Proton mail, paper files, WhatsApp)
   — the request covers all of it.
4. **Erasure**: Contact page → "Erase personal data". The screen says what the
   law makes us keep (AML records five years, sale records six years). Where a
   hold applies, the person's identity is removed from everything else and they
   are told which records remain and why.
5. **Rectification / restriction / objection**: edit the record; for an
   objection to marketing, untick marketing consent (the suppression record is
   kept so they are not emailed again).
6. **Reply in writing**, free of charge, and mark the request complete in the
   register with the outcome.
7. **Refusals** (manifestly unfounded or excessive, or a legal exemption) must
   be explained in writing with the person's right to complain to the ICO.

Search tips: the studio search box finds contacts by name, email and phone;
also search Proton Mail for the person's name and email address.
